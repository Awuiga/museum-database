# Музей — коллекции и экспонаты

Практическая работа по PostgreSQL, **вариант 14**.  
Кислощаев Дмитрий Михайлович · М26-555

Консольная программа для учёта музейных коллекций и экспонатов. За основу взят учебный проект `ProjectPostgreSQL`: таблицы `people` и `phone` заменены на `museum_collections` и `exhibits`.

## Возможности

- Просмотр, добавление, изменение и удаление коллекций.
- Работа с экспонатами выбранной коллекции: просмотр, добавление, изменение, удаление.
- Выбор записи по номеру в списке, без ввода ID из базы.
- Постраничный список (по 8 записей).
- Проверка дат, стоимости, размеров, текста и ответов «да/нет».
- При удалении коллекции автоматически удаляются её экспонаты.
- SQL-запросы с параметрами — пользовательский ввод не подставляется в SQL-код.

## Запуск

Нужны **Python 3.10+** и работающий **PostgreSQL**.

1. Создайте базу данных `museum_pg` (например, командой `CREATE DATABASE museum_pg;` в `psql`).
2. Откройте папку проекта в терминале и установите библиотеки:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Скопируйте пример настроек:

   ```powershell
   Copy-Item config.example.yaml config.yaml
   ```

4. Откройте `config.yaml`, укажите свой пароль PostgreSQL и проверьте порт. В примере стоит **5433** — на другом компьютере это может быть **5432**.
5. Запустите программу:

   ```powershell
   python main.py
   ```

При первом запуске программа создаст две таблицы, если их ещё нет. При повторных запусках данные сохраняются.

## Как пользоваться

В главном меню выберите `2`, чтобы создать коллекцию. Затем выберите `5`, укажите **номер коллекции в списке** и добавьте экспонат через `2`. Для возврата используйте `0`. Чтобы выйти из программы — `9`.

Для дат используется формат `ГГГГ-ММ-ДД`. Век вводится числом (`19` — XIX век, `-5` — V век до н. э.). Стоимость и размеры — неотрицательные и положительные числа соответственно.

## Файлы

- `main.py` — меню и действия пользователя.
- `dbconnection.py`, `dbtable.py` — подключение и запросы PostgreSQL.
- `tables/collections_table.py`, `tables/exhibits_table.py` — таблицы коллекций и экспонатов.
- `validation.py` — проверки введённых значений.
- `project_config.py`, `config.example.yaml` — загрузка и пример настроек.
