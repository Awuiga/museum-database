# База данных музея

Домашняя работа по проектированию базы данных, вариант 14. Используется SQLite.

База содержит информацию о музейных залах, коллекциях, экспонатах и стоимости билетов. Для связей коллекций с залами и билетов с залами используются отдельные таблицы.

## Запуск

```bash
sqlite3 museum.db < museum.sql
```

Команда создаёт таблицы в новой базе данных `museum.db`.
